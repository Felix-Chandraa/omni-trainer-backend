# R2 DEV-013 — Real Client Evidence Ingestion

DEV-013 connects authenticated Student clients to the DEV-012 Attempt recorder.
The server owns actor identity, Session/Attempt/Aircraft/generation, station and
training role. Client event payloads cannot replace those authoritative fields.

Evidence-only messages added to `omni.training.v1` are `clock_ping`,
`clock_pong`, `clock_sample` and `client_event`. Flight `cmd` messages remain
rejected.

Feather sends real `telemetry_received` acknowledgements at at most 2 Hz,
`ui_click`, control-key `key_down`, `visibility_changed` and `ui_client_ready`.
Typed text in input, textarea and contentEditable elements is deliberately not
recorded.

The live engineering proof uses a real ArduPlane+JSBSim worker, real FG state,
real MAVLink `.tlog`, and a real loopback WebSocket client. It proves clock
mapping, client-event ingestion, server-owned attribution, spoof resistance and
a fail-closed command path. It does not yet claim physical HOTAS input or a
manual Feather GUI run.

Replay remains the next layer: it will read stored trajectory plus per-station
events rather than re-running JSBSim from recorded controls.
