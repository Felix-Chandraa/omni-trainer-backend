# R2 DEV-006 — First Managed Live OMNI Launch

DEV-006 adalah titik pertama AircraftWorker R2 diizinkan menjalankan ArduPilot +
JSBSim aktual. Ini **engineering startup trial**, bukan training release, bukan
acceptance model, dan Attempt metadata sengaja tetap `Setup`.

## Kontrak live

- Tidak memanggil `run_demo.sh`.
- Tidak memakai `pkill`, `killall`, wipe `-w`, mission upload, parameter write,
  arm/mode/RC command, atau perubahan source/model.
- Standalone JSBSim hasil DEV-005 dibuat eksplisit melalui managed entry/PATH.
- Worker dijalankan dalam process-group milik DEV-004 dan stop hanya ke group itu.
- Visual/Feather Flight harus ditutup sementara karena DEV-006 mengikat UDP 5503
  secara eksklusif untuk membuktikan raw FGNetFDM langsung.
- Raw MAVLink dibuktikan dengan heartbeat receive-only melalui TCP 5762 memakai
  `pymavlink` dari venv checkout OMNI.
- Setelah stop, TCP 5760/5762 harus kembali bebas. Jika tidak, script melapor dan
  **tidak** melakukan cleanup global.

## Yang dianggap berhasil pada DEV-006

1. Managed worker tetap hidup selama startup.
2. Raw FGNetFDM v24 valid diterima langsung di UDP 5503.
3. Raw MAVLink HEARTBEAT diterima langsung di TCP 5762 tanpa mengirim command.
4. Worker tetap sehat pada observation window singkat.
5. Scoped stop mengakhiri worker dan port SITL kembali bebas.

## Yang belum ditutup

- Mission-loader companion sengaja belum dijalankan.
- UI/visual bus tidak menjadi bagian trial ini; DEV-003 sudah membuktikan jalur
  bus existing, sedangkan DEV-006 membuktikan channel raw terpisah.
- Full pause, command application, authority transfer, production authentication,
  worker recovery/adoption, per-aircraft port allocation untuk multi-instance,
  dan recording authoritative belum selesai.
- Flight behavior/model suitability sama sekali tidak dinilai oleh startup trial.
